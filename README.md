# 📊 Boletim Interativo

Um aplicativo web para gerenciar notas escolares, com cálculo automático de médias, controle de faltas e status de aprovação. Inclui funcionalidades de arrastar e soltar para reorganizar as matérias de forma intuitiva.

## ✨ Funcionalidades

- **Adição/Remoção de Matérias**
  - Adicione novas matérias personalizadas
  - Remova matérias indesejadas
  - Matérias padrão pré-cadastradas

- **Controle de Notas e Faltas**
  - Insira notas por semestre (0 a 10)
  - Registre faltas por semestre
  - Cálculo automático da média
  - Totalizador de faltas

- **Status de Aprovação**
  - Visualização imediata do status (Aprovado/Reprovado)
  - Destaque colorido para situações críticas

- **Organização Interativa**
  - Arraste e solte para reorganizar matérias
  - Edição de nomes com duplo clique
  - Persistência de dados via `localStorage`

## 🛠️ Tecnologias Utilizadas

- **Frontend**
  - HTML5 semântico
  - CSS3 com Flexbox
  - JavaScript puro (ES6+)

- **Ferramentas**
  - Font Awesome para ícones
  - Google Analytics para métricas
  - `localStorage` para persistência de dados
